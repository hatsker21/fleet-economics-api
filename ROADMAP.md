🗺 Roadmap: B2B Fleet Economics API
📍 Етап 1: Ініціалізація та База Даних (Фундамент)
Мета: Підняти працюючий сервер, підключити БД та налаштувати систему міграцій.

[ ] Написати базовий код FastAPI (src/main.py), налаштування (src/config.py) та БД (src/database.py).

[ ] Запустити сервер та перевірити /health ендпоінт.

[ ] Написати SQLAlchemy моделі для Company, User, Location (src/models/).

[ ] Ініціалізувати Alembic (alembic init alembic).

[ ] Налаштувати alembic/env.py для підключення наших моделей.

[ ] Згенерувати та застосувати першу міграцію (alembic revision --autogenerate, alembic upgrade head).

📍 Етап 2: Реєстрація, Авторизація та RBAC (Безпека)
Мета: Реалізувати систему користувачів з ролями та безпечним доступом.

[ ] Створити Pydantic-схеми для реєстрації та логіну (src/schemas/user.py).

[ ] Написати утиліти для хешування паролів та генерації JWT-токенів (src/api/auth_utils.py).

[ ] Реалізувати ендпоінт POST /auth/register (створення компанії та адміна).

[ ] Реалізувати ендпоінт POST /auth/login (отримання токена).

[ ] Написати Dependency get_current_user, яка перевіряє токен та витягує юзера з БД.

[ ] Написати Dependency для перевірки ролей (RBAC) та ізоляції компаній (Tenant Isolation).

📍 Етап 3: Основний CRUD (Операційні дані)
Мета: Навчити API створювати, читати, оновлювати та видаляти основні сутності.

[ ] Додати SQLAlchemy моделі для Vehicle, Trip, FuelLog, MaintenanceLog.

[ ] Зробити міграцію для нових таблиць.

[ ] Реалізувати Vehicles CRUD (з жорсткою перевіркою company_id).

[ ] Реалізувати Trips CRUD.

[ ] Реалізувати Locations CRUD (або просто скрипт для заповнення базових міст).

📍 Етап 4: Витрати та Фільтрація (Advanced Features)
Мета: Зробити API зручним для аналізу даних.

[ ] Реалізувати CRUD для FuelLogs та MaintenanceLogs.

[ ] Додати пагінацію (limit, offset) для списків рейсів та автомобілів.

[ ] Додати фільтрацію рейсів за датою (?start_date=...&end_date=...).

[ ] Реалізувати механізм Soft Delete для рейсів та користувачів (щоб не видаляти дані фізично).

📍 Етап 5: Economics Engine (Бізнес-логіка)
Мета: Реалізувати головну фішку проєкту — розрахунок рентабельності.

[ ] Створити EconomicsService (окремий клас або модуль).

[ ] Написати логіку збору даних (доходи з рейсів, витрати на пальне, ремонти).

[ ] Реалізувати розрахунок амортизації ((purchase_price - residual_value) / expected_life_km).

[ ] Додати розрахунок CASK, RASK, Load Factor та Net Profit.

[ ] Створити ендпоінт GET /vehicles/{id}/economics для видачі зведеного звіту.

📍 Етап 6: Деплой та Підготовка до захисту (Production)
Мета: Показати проєкт світу та підготуватися до презентації.

[ ] Перевести базу з SQLite на PostgreSQL (створити базу на Render/Supabase).

[ ] Задеплоїти API на публічний сервер (наприклад, Render або Railway).

[ ] Оформити фінальний README.md з прикладами curl запитів до живого сервера.

[ ] Протестувати API на живому сервері, створити тестових юзерів і рейси.
